# Security policy

## Report a vulnerability

Please report suspected vulnerabilities privately to [development@koadic.dk](mailto:development@koadic.dk). Do not open a public issue or include customer data, passwords, API keys, or other secrets in a report.

Include the affected Koadic product or repository, the steps needed to reproduce the issue, and its potential impact. We will review the report and coordinate next steps. We do not promise a specific response time or service level.

## Scope and safe testing

This route is for security concerns affecting software and services operated by Koadic Developments. Only test systems and accounts you own or have explicit permission to assess. Do not access, alter, or retain another person's data.

Please allow us time to investigate and address a confirmed issue before sharing details publicly.
